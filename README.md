## Descripción del proyecto
Este proyecto consiste en el desarrollo de una aplicación web interactiva para explorar un conjunto de datos de anuncios de venta de vehículos. La aplicación utiliza Streamlit para crear una interfaz web y Plotly Express para generar gráficos interactivos. 

## Objetivos
* Analizar los datos de vehículos usados.
* Explorar la relación entre el kilometraje y el precio.
* Visualizar la distribución del kilometraje mediante histogramas.
* Crear gráficos interactivos para facilitar el análisis.
* Desarrollar una aplicación web utilizando Streamlit.

## Funcionalidad
La aplicación permite:
* Visualizar la distribución del kilometraje de los vehículos.
* Analizar la relación entre kilometraje y precio mediante un gráfico de dispersión.
* Interactuar con los gráficos para explorar los datos.
* Consultar los resultados del análisis de manera visual y sencilla.

## Tecnologías utilizadas
* Python
* Pandas
* Plotly Express
* Streamlit
* Jupyter Notebook
* Git y GitHub
